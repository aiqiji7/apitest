# PRD: UI改进 - 代理框折叠 + 模型搜索

## 需求概述

两项UI改进，提升用户体验和界面整洁度。

## 需求 1: HTTPS代理框默认折叠

### 当前状态
- HTTPS代理输入框始终显示
- 使用黄色/琥珀色设计（边框 #fbbf24，背景 #fffbeb）
- 代理标签也是黄色背景

### 目标状态
- 代理框默认折叠，不占用界面空间
- 用户可通过点击展开/收起
- 去掉黄色设计，使用与界面一致的中性风格

### 实现要点
1. HTML: 添加一个可点击的触发元素（如"设置代理"链接/按钮）
2. CSS: 
   - 移除黄色边框和背景
   - 使用与其他输入框一致的样式（#cfe6ff 边框）
   - 添加折叠/展开动画
3. JS: 
   - 默认隐藏代理输入区域
   - 点击触发元素时切换显示状态
   - 保持现有的警告状态逻辑（http:// URL无代理时的高亮）

## 需求 2: 模型输入框搜索功能

### 当前状态
- 模型输入框是自由文本
- 点击刷新按钮从API获取模型列表
- 下拉列表显示所有模型，无过滤功能

### 目标状态
- 用户输入时自动过滤已获取的模型列表
- 支持模糊匹配（模型ID包含输入文本）
- 无需重新请求API即可快速筛选

### 实现要点
1. JS: 
   - 监听模型输入框的 input 事件
   - 如果已有缓存的模型列表，根据输入文本过滤
   - 过滤逻辑：模型ID包含输入文本（不区分大小写）
   - 实时更新下拉列表显示
2. 保持现有功能：
   - 刷新按钮仍然可以重新从API获取
   - 手动输入任意模型名仍然有效
   - 选择模型后填充输入框

## 技术约束

- 纯前端实现（HTML/CSS/JS）
- 保持现有代码风格和结构
- 不引入新依赖

## 验收标准

1. 代理框默认不可见，点击后展开，再点击收起
2. 代理框样式与整体界面风格一致（无黄色元素）
3. 在模型输入框中输入文本时，下拉列表自动过滤显示匹配的模型
4. 过滤是实时的，无需按回车或点击按钮
5. 所有现有功能保持正常（API获取、手动输入、警告状态等）
